# Agent Instructions

_Last updated: 2026-09-06_

Before any implementation work in this repository, follow [`init.md`](init.md) in full.

1. Execute the Session Initialization Protocol in `init.md` (Phases 1–4). Do not skip or reorder steps.
2. Orient from the harness docs it lists (`docs/constitution.md`, `docs/status.md`, `docs/roadmap.md`, `docs/agents.md`, specs, decisions, architecture) before editing.
3. Declare session scope before the first file change; close the session with the status/roadmap/trace updates `init.md` requires.

`init.md` is the source of truth for session start, scope, implementation rules, and session close. Do not reinvent that protocol here.
